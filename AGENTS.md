# AGENTS.md

Cloudflare Worker that serves `files.point.com` from the `marketing-cdn` R2 bucket, plus password-protected
admin tools (`/upload`, `/browse`, `/code`) and their JSON APIs. Plain JavaScript, type-checked with JSDoc.

## Layout

- `src/index.js` - the whole worker: routing, auth cookies, upload/replace/delete, asset serving (CORS, range requests)
- `src/index.test.js` - Vitest tests; call `worker.fetch` with mock `CDN_BUCKET` stubs (no Miniflare)
- `src/ui/*.html` - admin UI templates, imported as text modules (wrangler `[[rules]]` Text; `vitest.config.js` plugin in tests)
- `src/env.d.ts` - secret bindings (`UPLOAD_PASSWORD`, `CODE_PASSWORD`, `CF_API_TOKEN`) that `wrangler types` cannot see
- `worker-configuration.d.ts` - generated by `npm run wrangler:types`; commit it, do not hand-edit
- `wrangler.toml` - routes, R2 binding, vars (`CDN_PUBLIC_BASE`, `CF_ZONE_ID`)
- `webflow-extension/bundle.zip` - prebuilt Webflow extension bundle (not built from this repo)

## Verify

```bash
npm ci
npm run check   # wrangler types --check + tsc (checkJs, strict) + vitest run
```

CI (`.github/workflows/ci.yml`) runs `npm run check` on every PR and on pushes to `main`.

Other scripts: `npm test`, `npm run typecheck`, `npm run format:check` (Prettier; the repo does not pass it yet,
so it is not part of `check`).

## Run locally

```bash
npm run dev   # wrangler dev
```

Local dev needs secrets in `.dev.vars` (`UPLOAD_PASSWORD`, `CODE_PASSWORD`, optionally `CF_API_TOKEN`). Do not commit it.
If `.dev.vars` exists when you run `npm run wrangler:types`, its keys end up in the generated file; regenerate without it.

## Conventions and gotchas

- npm is the package manager. Do not add `bun.lock` or `yarn.lock`.
- Type errors are real: `tsconfig.json` has `checkJs`, `strict`, and `noUncheckedIndexedAccess`. Use JSDoc
  (`@param`, `@returns`, `/** @type {X} */ (expr)` casts) rather than `// @ts-ignore`.
- After changing `wrangler.toml`, run `npm run wrangler:types` or `typecheck` fails.
- `ALLOWED_ORIGINS` (CORS allowlist for `code/` assets) is hardcoded in `src/index.js`, not an env var.
- `PROTECTED_PREFIXES` (`code/`, `analytics/`, `marketing-tools/`, `marketing/`, `careers/`) are hidden from `/browse`
  and cannot be replaced. marketing-tools duplicates this list as `EXCLUDED_PREFIXES` in `src/tools/cdn-files/storage.ts`; change both.
- `/upload` never overwrites; duplicate names get `-1`, `-2` suffixes. `/api/replace-file` overwrites in place and
  purges the Cloudflare cache when `CF_ZONE_ID` and `CF_API_TOKEN` are set.
- Missing objects and `/` redirect (302) to `https://point.com`.
- Formatting: tabs, single quotes, semicolons, 140-column width (`.prettierrc`, `.editorconfig`).

## Do not run

These deploy or write to production (the `files.point.com` worker and the shared `marketing-cdn` bucket):

- `npm run deploy` / `wrangler deploy`
- `wrangler secret put ...` / `wrangler secret delete ...`
- `wrangler r2 object put|delete ...` or any other write to the `marketing-cdn` bucket
- `wrangler dev --remote` (binds to the real bucket)
- POST/DELETE against `https://files.point.com` (`/upload`, `/api/replace-file`, `/api/delete-file`)

pdc-code's GitHub Actions also upload to `code/staging/` and `code/prod/` in this bucket; don't write there by hand.
